- Phase 23 diagnosed the intermittent Phase 15 gizmo UI failure that Phase 22 attempt 1 recorded. The gumball's three plane tiles were drawn after the axis arrows, so after an orbit a plane tile's 24 pt hit area could sit inside an arrow's 44 pt target. A drag aimed at the X arrow then ran a plane gesture: in Phase 22's run it snapped to zero and read `X 0.000 · Y 40.000 · Z 0.000`; in Phase 23 run 42379914191 it moved in YZ and read `X 0.000 · Y 35.000 · Z -4.000`. `11996c1` draws the arrows last, so the visible arrow owns its target; Phase 23's smoke now orbits before the drag and asserts the full `X -10 · Y 40 · Z 0` result, so the class cannot silently recur. The fix is app code, not a retry. Phase 23 also confirms that reopen resets ephemeral selection by design; the smoke reselects the stone at its captured screen point before reading the restored transform.
